# Orbit — Space Quiz

A colorful, responsive space exploration quiz with ten questions, instant answer feedback, a live score, and an emoji results screen.

## Play

Open `index.html` in any modern browser. There is no server, build step, installation, or external dependency.

## Features

- Ten multiple-choice questions with short explanations
- Progress bar and score counter
- Animated green correct-answer and red incorrect-answer feedback
- End screen with score-based emoji reaction
- System light/dark theme and reduced-motion support
- Responsive, keyboard-accessible layout

## Project structure

- `index.html` — the complete app, including all markup, styles, quiz content, and behavior
- `AGENTS.md` — project-specific instructions for coding agents
